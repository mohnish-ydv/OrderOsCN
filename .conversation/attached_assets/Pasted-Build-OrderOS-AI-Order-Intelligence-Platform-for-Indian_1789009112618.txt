Build OrderOS — AI Order Intelligence Platform for Indian Distributors

Build a production-quality SaaS/web application called OrderOS.

1. Product

OrderOS is an AI-powered order intelligence system for Indian distributors, wholesalers and manufacturers.

Core promise:

«Your dealers talk. OrderOS turns it into verified orders.»

The system converts messy incoming orders — text, Hinglish, voice notes, images, screenshots and PDFs — into structured sales orders.

It must NOT be positioned as another generic ERP, CRM or chatbot.

The core workflow is:

Messy dealer message → AI interpretation → SKU matching → validation → exception handling → human approval → order

The dealer should NOT need to install a separate app.

3. Core Differentiator

The most important feature is Dealer Memory.

Different dealers use different names, abbreviations, quantities and language.

Example:

Dealer:

«"bhai 20 anchor 6A, 10 16A socket, 5 2.5 blue aur 3 red coil"»

OrderOS should understand that using the distributor's catalogue and historical data.

Another dealer may say:

«"same last wala + 10 MCB"»

The system should use historical orders to determine what “same last wala” means.

Store learned mappings such as:

Dealer: Sharma Electricals

"blue 2.5"
→ Finolex 2.5mm Blue Wire

"red coil"
→ SKU-4821

"32 wala"
→ L&T 32A MCB

"one box"
→ 10 units

"same rate"
→ last negotiated dealer-specific price

Dealer-specific terminology must NEVER be globally applied to another dealer.

37. AI Architecture

Separate AI from deterministic business logic.

AI handles:

- OCR interpretation
- transcription
- entity extraction
- product matching
- ambiguity detection
- language understanding
- dealer-language interpretation

Deterministic code handles:

- prices
- totals
- GST calculations
- stock calculations
- credit limits
- business rules
- permissions
- approval state

Never allow the LLM to be the source of truth for financial calculations.

---

38. Structured AI Output

AI should return strict structured data.

Example:

{
  "items": [
    {
      "raw_text": "blue 2.5",
      "matched_sku": "FIN-25-BLU",
      "quantity": 5,
      "unit": "coil",
      "confidence": 0.97
    }
  ],
  "ambiguities": [],
  "overall_confidence": 0.97
}

Validate all AI output against a schema before using it.

44. Important Product Principle

OrderOS should always answer:

«What does the human actually need to do?»

If the AI is confident:

Don't interrupt the human.

If the AI is uncertain:

Show exactly what is uncertain.

If a business rule fails:

Explain why.

If an order is ready:

Make approval extremely fast.

The product is fundamentally an exception-management system, not a dashboard.
